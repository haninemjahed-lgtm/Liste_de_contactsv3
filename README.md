# Liste de contacts V3

Application Android (Kotlin) : Fragments, RecyclerView, filtrage, Google Maps.

## Configuration

Créer un fichier `local.properties` à la racine du projet avec :

MAPS_API_KEY=votre_cle_google_maps

(Maps SDK for Android doit être activé sur votre projet Google Cloud.)
Le fichier `local.properties` n'est pas publié sur GitHub.
